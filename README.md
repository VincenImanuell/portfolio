# Portfolio Site

Portfolio satu halaman dengan Next.js, TypeScript, Tailwind CSS, dan Lucide icons.

## Menjalankan lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Sebelum deploy

Edit data placeholder di `app/page.tsx` dan metadata di `app/layout.tsx`:

- `Your Name`, inisial `YN`, email, lokasi, dan angka pengalaman
- daftar project, role, dan link LinkedIn/GitHub
- title serta description halaman

Untuk Vercel, import repository ini lalu gunakan pengaturan default Next.js. Build command-nya adalah `npm run build`.
